# Frank Faruk Ceviz

Audio engineer, producer and sample library developer in London. I have been recording and editing audio since 1997.

**What I do**
- Clean and restore audio in iZotope RX 11 almost every day: hiss, room reflections, clicks and pops, ringing and high-frequency faults, attack and decay problems.
- Record, edit and program sampled instruments for Decent Sampler, sold through my own business, FF Sampling.
- Build my own tools with AI coding (mainly Claude Code) to speed up sampling work: renaming and organising thousands of audio files, checking instruments, tuning and mapping.

**Tools I use**
iZotope RX 11 · Melodyne · Logic Pro · Ableton Live · Pro Tools · Kontakt · Decent Sampler (XML) · Python · JavaScript · React · Node.js

**Background**
Ran my own commercial studio (Audio Allegro), recording and mixing sessions for 20+ artists. Composed and produced for film and TV (Channel 4, Channel 5). MA Composing for Film & TV, Kingston University.
